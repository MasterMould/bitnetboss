🛡️ BitNet Omni-Archive Suite (v2026.7)The BitNet Omni-Archive Suite is a high-performance, local-first AI workstation deployment designed for Ubuntu 24.04. It leverages the revolutionary 1.58-bit ternary quantization ($\{-1, 0, 1\}$ weights) to provide LLM inference that is significantly faster and more energy-efficient than traditional 8-bit or 4-bit models.🌟 Core FeaturesUniversal GPU Acceleration: * Intel Arc A770: Optimized via oneAPI/SYCL and Xe Matrix Extensions (XMX).AMD Radeon RX 570/Polaris: Supported via ROCm/HIP (gfx803).NVIDIA: Full CUDA support for Tensor Core acceleration.Omni-Parser: Native support for chatting with PDF, DOCX, CSV, XLSX, and Markdown.Persona Library: Six pre-configured system roles (Senior Coder, Data Analyst, Socratic Teacher, etc.).Multimodal Vision: Support for BitVLA image analysis.Voice Pipeline: Integrated Whisper STT (Speech-to-Text) and Piper TTS (Text-to-Speech).Auto-Log: Every session is timestamped and archived to ./chat_logs/history.log.Open WebUI: A beautiful, browser-based interface with integrated RAG (Retrieval Augmented Generation).🚀 Installation & Setup1.
